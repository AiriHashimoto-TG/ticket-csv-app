チケット入稿CSVジェネレーター for Matrixify / Shopify

公演日ごとの商品・30分刻みの時間枠・平日/休日価格・祝日判定・最終日短縮を自動展開して、Matrixify取り込み用CSVを書き出します。

1 イベント共通設定

固定設定（通常は変更不要：Shopify項目・公開設定）

2 時間枠テンプレート（毎日共通）

左=在庫 / 右=先頭何枠に適用
↓ 自動生成された枠。個別に在庫を上書きできます（短縮日でも「最後の枠」は自動で最終枠在庫になります）。

3 価格・休日判定

土曜・日曜・日本の国民の祝日（振替休日・国民の休日を含む）を自動で「休日価格」にします。個別の例外は各会場の「例外日」で上書きできます（例：7/7を平日に固定）。

4 会場・期間

5 集計と出力

CSVプレビュー（先頭30行）

使い方メモ

① 会場ごとに 期間・画像URL・会場名 を入れる → ② 例外日（短縮/平日固定など）を登録 → ③「CSV」を押す → ④ Matrixify の Import で取り込み。

列構成は現行の Matrixify ファイルに合わせて出力します（Excelで開いても文字化けしないUTF-8 BOM付き）。

設定は自動保存されます。別PCへは「設定を保存(JSON)」で引き継げます。

1 Matrixifyでエクスポートした商品ファイルを読み込む

CSVファイルをここにドロップ または クリックして選択

Matrixify の Export → Products を CSV形式 で書き出したファイル（Handle / Variant ID / 現在庫が入っているもの）

エクスポート手順（Matrixify）
Matrixify → Export → 対象に Products を選択 → 必要なら Filter で対象コレクション/期間に絞る → Format を CSV → Export。
出力ファイルには最低限 Handle Variant ID Option1 Value Variant Inventory Qty が含まれていればOKです。

2 追加する在庫を入力

出力モード：
現在庫に対して入力した数を足し引きします（Variant Inventory Adjust）。
